# Pedalboard MIDI

Pedalboard MIDI profile metadata is centralized in `audio/dot-local/share/dotfiles/pedalboard-midi-profiles.tsv`; host tools should query it through `pedalboard-midi-profiles` instead of hardcoding profile names, channels, CCs, aliases, action-mapper units, or TFT IDs.

`pedalboard-midi-profile` changes the Arduino profile over serial and starts only the host action mapper declared by the selected TSV row. `pedalboard-midi-actions` loads the same TSV at startup to publish TFT state from incoming CC events.

The `obs-mouseless-setup` profile reuses the continuous pedal on channel 15 CC4 for the Kitty/Neovim teleprompter: `pedalboard-midi-actions` treats `teleprompter-scroll` as a built-in FIFO send, writes only changed mapped CC values to the active `DOTFILES_TELEPROMPTER_SCROLL_FIFO` after clamping values at or below `DOTFILES_TELEPROMPTER_DEADZONE` to 0, and does nothing when no teleprompter FIFO exists. The default deadzone follows `PEDALBOARD_MIDI_SHIFT_THRESHOLD` and is 21; `DOTFILES_TELEPROMPTER_FAST_THRESHOLD` defaults to 64 and splits the active range into slow and faster buckets. The Neovim-side timer starts at 0, consumes only live FIFO events, and maps 0 to stopped, light-to-half pressure to slow scrolling, and full pressure to a modestly faster scroll. The TFT feedback path publishes only when the teleprompter speed bucket changes, using representative MIDI values `0`, `64`, and `127`; the display renders those as `VEL 0`, `VEL 1`, and `VEL 2`. The `obs-scene-toggle --monitor` service keeps OBS as the source of truth for the scene tile by reading the current program scene through OBS WebSocket and publishing `SCENE <token>` to the TFT when OBS reports a current-scene change. Do not put per-event shell, persistent-value files, TFT feedback updates, or Neovim RPC calls on this continuous MIDI path. The middle switch remains mapped to `desktop-action-run obs-scene-toggle`.

Firmware still embeds the profile table because the Arduino cannot read the host TSV at runtime; update the firmware table and TFT label/ID handling alongside the TSV, and keep tests checking those contracts together.

`Ctrl+Alt+B` and `Ctrl+AltGr+B` open `pedalboard-midi-profile-picker` through keyd, using the same Kitty/fzf quick-access style as snippets and Vim registers.
